# Intelligent Robotic Systems Lab Activities

## Overview

This repository contains the laboratory assignments completed for the Intelligent Robotic Systems course. Each lab focuses on a different a differet discipline taught in the course. 


---

## Repository Structure

```text
.
├── Lab_activity-2/
├── Lab_activity-3/
├── Lab_activity-4/
├── Lab_activity-5/
├── Lab_activity-6/
└── README.md
```

Each folder contains the argos file, lua file, lab activity description and the report explaining results. 


---

# Lab Summaries

## Lab 2: Composite Behaviors

### Objective

Implementing a simple controller that applies two behaviors Phototaxis and Obstacle Avoidance


---

## Lab 3: The Subsumption Architecture

### Objective

Implementing a subsumption architecture with the following behaviors: Halt on black spot, obstacle avoidance, phototaxis and random walk


---

## Lab 4: Motor Schemas

### Objective

Implement a controller using Motor Schemas with the following behaviors: Phototaxis, obstacle avoidance and random walk

---

## Lab 5: Explorations in Evolutionary Robotics

### Objective

Designing a control software by means o evolutionary computation. Main goal is to experiment with Evolutionary Robotics in a simple scenario. 


---

## Lab 6: Swarm Robotics

### Objective

Developing a controller that executes aggregation, in which robots gather in one place.
